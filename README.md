# SOLE Ultimate Media Dashboard

Phase 2 Monster Build.

## Host on GitHub Pages
Upload `index.html`, `sources.json`, and `README.md` to the repo root.

Then:
Settings → Pages → Deploy from branch → main → /root → Save.

Live URL:
`https://YOURUSERNAME.github.io/sole-dashboard/`

## APK Builder
Use the GitHub Pages URL as website URL.

Permissions:
- Internet: ON
- Download support: ON if builder offers it
- External storage: avoid unless builder requires it; modern Android uses DownloadManager/MediaStore/app-specific storage.

## Safety
Use legal/free sources and avoid malware-heavy APKs or forced VPN/profile installs.
